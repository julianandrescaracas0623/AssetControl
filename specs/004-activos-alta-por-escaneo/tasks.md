## Guía de la prueba con teléfonos reales (A6, la hace el humano)

1. Backend y base al día: `cd backend && uv sync && uv run alembic upgrade head`; levantar la API como siempre.
2. Web: `cd web && npm ci`, luego `VITE_HTTPS=1 npm run dev` (PowerShell: `$env:VITE_HTTPS=1; npm run dev`). Permitir el puerto 5173 en el firewall de Windows si el teléfono no carga.
3. En cada teléfono (al menos un Android y un iPhone si los hay), en la misma wifi: abrir `https://<ip-del-computador>:5173`, aceptar el aviso del certificado, iniciar sesión como contador y permitir la cámara.
4. Lectura (cierra P4): en **Contar → Escanear**, apuntar a 10 stickers reales distintos, con buena luz y con poca luz, a 10–30 cm. Anotar por teléfono cuántos lee al primer intento, cuántos tardan más de 3 s y cuáles no lee (foto del sticker si falla). Probar también un sticker gastado o curvo.
5. Tiempo de alta (P10): con un cronómetro, desde que se apunta a un sticker nuevo hasta "Activo registrado", copiando de un parecido. Meta: menos de 30 s. Repetir 5 veces y anotar el promedio.
6. Formatos (cierra P9): si algún sticker no lee, anotar qué dice debajo de las barras y su tipo si se conoce (Code 128, Code 39, EAN…). Revisar que el código guardado sea idéntico al impreso.
7. Comprobar que el contador nunca ve precio y que el admin, desde el computador, ve los activos creados en **Activos**.
8. Pasar los resultados a esta sección (tabla por teléfono: modelo, navegador, leídos, fallidos, tiempo medio) o contárselos a la siguiente sesión.
